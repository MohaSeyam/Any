# منظومة قاعدة البيانات المحلية المؤمّنة — الإصدار المحصّن V2 (صور + مرفقات + 100GB بدون SD)

تطبيق أندرويد يعمل **محلياً بالكامل وبدون إنترنت نهائياً (`100% Air-Gapped`)** مع قاعدة بيانات مشفرة عبر **`SQLCipher 4` (`AES-256 + Per-Page HMAC-SHA512`)** بصلاحية **القراءة فقط (`OPEN_READONLY`)**، مصمم للتعامل مع قواعد بيانات ضخمة (**~100 جيجابايت**) تشتمل على **صور عالية الدقة ووثائق `PDF` ومرفقات نصية**.

---

## 1. أبرز التحسينات الهندسية والأمنية في الإصدار V2

1. **دعم الصور والمرفقات الضخمة دون انهيار الذاكرة (`Chunked BLOB Streaming`):**
   * فصل عمودي للجداول (`catalog_records` + فهرس `catalog_fts` السريع للنصوص، معزولين تماماً عن جدول البيانات الثنائية `attachment_blobs`) لضمان سرعة بحث بالميلي ثانية حتى مع حجم 100 جيجابايت.
   * قراءة الصور والمرفقات على شرائح آمنة (`512 KB` عبر `SUBSTR`) لتجاوز قيد أندرويد الشهير (`CursorWindow 2MB Limit`) الذي يتسبب بانهيار التطبيقات التقليدية عند فتح صور أكبر من `2 MB`.
   * التحقق التشفيري من بصمة **`SHA-256`** الكاملة لكل صورة أو ملف `PDF` أثناء البث قبل عرضه.
2. **عارض داخلي آمن بالذاكرة (`Zero-Disk-Residue Viewer`):**
   * **عارض صور تفاعلي (`ZoomableSecureImageView`):** تكبير بإصبعين (`Pinch-to-Zoom 1x..6x`) وتحريك ونقر مزدوج مع تحجيم ذكي للأبعاد (`inSampleSize`) لمنع استنزاف الذاكرة وتصفير البايتات الخام فور فكها.
   * **عارض `PDF` داخلي متعدد الصفحات (`PdfRenderer`):** يعمل عبر واصف ملف محذوف الرابط فوراً (`Anonymous Unlinked File Descriptor`) بحيث لا يبقى أي ملف قابل للوصول على القرص!
   * فرض `FLAG_SECURE` لمنع تصوير/تسجيل الشاشة + علامة مائية قطرية باسم المستخدم ومعرّف الجهاز.
3. **تغليف غير متماثل لمفتاح القاعدة (`RSA-2048 OAEP` داخل `Android Keystore`):**
   * مفتاح تشفير قاعدة البيانات (`DEK`) **لا يظهر مكشوفاً أبداً** لا في طلب التفعيل (`REQ2`) ولا في شهادة الترخيص (`LIC2`)، بل يُشفّر بالمفتاح العام لشريحة `Android Keystore` الخاصة بالهاتف المستهدف حصراً.
4. **مقاومة استرجاع ملف العداد عتادياً (`Hardware Keystore Anti-Rollback`):**
   * عند حدوث إغلاق نهائي (المحاولة العاشرة أو تلاعب بالوقت أو حذف ملف)، يتم **تدمير مفتاح تشفير العداد النشط داخل شريحة `Android Keystore`**؛ فلو حاول مهاجم استعادة نسخة قديمة من ملف العداد (`= 0`) تفشل عملية فك التشفير فوراً ويبقى الجهاز مغلقاً لحين نقله فيزيائياً للمدير!

## 3. خطوات التجريب العملي (مع الصور والـ PDF)

1. **إنشاء القاعدة التجريبية بالصور والمرفقات:** افتح التطبيق لأول مرة واضغط **"1. إنشاء قاعدة بيانات مشفرة تجريبية (SQLCipher)"** — سيولّد التطبيق قاعدة مشفرة تحتوي على `250` سجلاً مفهرساً بـ `FTS5`، تشمل مخططات `PNG`، وصورة فحص عالية الدقة بحجم **`2.76 MB`** (فوق حاجز `2MB`)، ومستندات **`PDF` من صفحتين**، وتقارير نصية، ويخرج المفتاح الأولي المحمي (`REQ2....`).
2. **إصدار الترخيص الخاص بالجهاز من حاسوب الإدارة:**
   ```powershell
   python admin_tool.py issue-license --request "<REQ2_CODE>" --admin-password "AdminSecret#2026" --valid-days 30
   ```
3. **إتمام التفعيل وتعيين حساب المستخدم:** امسح رمز `QR` الناتج (أو الصق `LIC2....`)، أدخل كلمة مرور الأدمن `AdminSecret#2026`، ثم عيّن `Username` و `Password` للمستخدم الميداني.
4. **استعراض السجلات والصور وملفات PDF:** سجّل الدخول، افتح السجل الأول (`SEC-REF-00001`)، وجرّب فتح المخطط الهندسي وتكبيره بإصبعين، وفتح الصورة ذات الحجم `2.76 MB`، والتنقل بين صفحات ملف الـ `PDF` المشفر!
5. **الفتح الحضوري الفيزيائي لدى المدير (عند الإغلاق النهائي):**
   ```powershell
   python admin_tool.py unlock-device --challenge "<UNLKREQ2_CODE>" --admin-password "ManagerUnlock#99"
   ```
